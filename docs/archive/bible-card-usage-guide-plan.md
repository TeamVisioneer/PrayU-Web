# 말씀카드 생성 횟수 안내 개선 계획

## 배경

생성 횟수가 0이 된 사용자에게 나가는 안내가 불완전하다:

- 소진 toast "…내일 다시 만들 수 있어요"는 공유 보상 도입 전 문구 — 공유하면 오늘도 만들 수 있다는 정보 누락
- "공유하면 +1"의 인정 조건(채팅방 공유 성공, 나와의 채팅 제외, 동일 채팅방 1일 1회)이 제품 어디에도 없음
- 말씀카드의 매치 원리(기도카드 내용 기반 구절 선택)와 카운트 규칙(일 3회, 자정 리셋, 재생성 차감)에 대한 설명 부재

방향은 사용자 확정: 소진 toast 문구 정합화 + 생성 페이지 캡션 옆 ⓘ → 안내 bottom sheet.

## 확정 문구

- 소진 toast: **"오늘 생성 횟수를 모두 사용했어요. 카카오톡으로 공유하면 1회 더 만들 수 있어요"**
- 안내 시트:
  - 제목: **말씀카드는 어떻게 만들어지나요?**
  - 본문: 선택한 기도카드의 기도제목과 나눔 내용을 바탕으로, 어울리는 성경 구절을 골라 나만의 말씀카드를 만들어 드려요.
  - **생성 횟수 안내**
    - 하루 3회까지 만들 수 있어요 (매일 자정 초기화)
    - 말씀카드를 다시 만들 때도 1회가 사용돼요
    - 만든 카드를 카카오톡 채팅방에 공유하면 1회가 추가돼요
    - 같은 채팅방 공유는 하루 1번만 인정되고, 나와의 채팅은 제외돼요
