# 데일리 기록 + "오늘" 허브 (v1.2)

상위: [overview.md](overview.md) · 상태: **방향만** — v1.1(재편) 뒤에 구체화

## "오늘" 홈 스케치 — 기존 자산 조립 + 새 살 하나

```
[ 오늘 ]
  오늘의 말씀 / QT 본문           ← 성경 DB + QT (있음)
  ✍ 오늘의 묵상 기록              ← 새 기능 (기록 엔티티)
  🙏 오늘의 기도                  ← 있음 (오늘의기도 + 리마인더 cron)
  📿 기도 달력 · 스트릭            ← 있음 (프로필에서 승격)
  👥 그룹 소식 요약                ← "새 기도카드 N개" 요약 카드 (본문 노출 아님)
```

v1.0.0 네비의 홈 탭(`/` MainPage)을 이 화면으로 교체한다.

## 기록 엔티티

- **첫 습관은 묵상(QT) 일기 권고** — 기존 QT 흐름에 "내 기록"을 붙이는 것이라 가장 싸고,
  매일성경 사용자층(관찰/해석/적용 워크북 문화)과 정확히 겹친다
- 기도 일기(수시)·설교노트(주 1회, 에디터 필요)는 케이던스가 다른 별개 행동 — 각각 뒤 단계
- 기본값 **나만 보기**. 그룹 공유는 [pray-card-restructure.md](pray-card-restructure.md)의 share 모델 재사용
- v1.1 재편이 끝나면 묵상 기록은 `pray_card` 의 **형제 엔티티**로 자연스럽게 들어온다

## 시즌 챌린지 — 후순위, 그러나 버리지 않는다

Hallow 성장의 핵심 장치(사순절 Pray40 = 매년 앱스토어 1위)의 한국판:
**특새·40일 작정기도·사순절 — 그룹 단위로.** "우리 청년부 40일 묵상 함께" — 그룹장이 열고,
멤버 스트릭이 그룹에 보이고, 완주를 함께 기념. 그룹 해자 × 데일리 습관의 결합점이자
교회 단위 확산 경로. **데일리 습관(기록·스트릭)이 자리잡은 뒤에** 얹는다.
