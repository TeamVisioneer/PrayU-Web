# 피드

상위: [overview.md](overview.md) · 상태: **설계 전, 결정 대기 항목이 가장 많다**

## 목표

홈 탭에서 세 가지가 섞여 흐른다:

1. **팔로잉한 사람의 게시물**
2. **공개 게시물** (모르는 사람 것도)
3. **내 그룹에서 업데이트된 기도카드**

## 🔴 1. 먼저 정해야 할 것 — "게시물"이 무엇인가

여기서 설계가 완전히 갈린다. 이 결정 없이는 아래 어느 것도 확정할 수 없다.

| 안 | 내용 | 장점 | 대가 |
|---|---|---|---|
| **A. 기존 콘텐츠를 흘린다** | `pray_card`·`thanks_card`·`bible_card` 를 피드 아이템으로 | 새 테이블 없음. 이미 쌓인 콘텐츠가 바로 피드를 채운다 | 세 테이블을 시간순으로 합치는 쿼리가 복잡. 각각 성격이 달라 카드 UI 가 제각각 |
| **B. 새 `post` 엔티티** | SNS 게시물 테이블을 따로 만든다 | 피드 설계가 깔끔. 좋아요·댓글을 한 곳에 붙인다 | 콘텐츠가 0에서 시작 — **빈 피드 문제**. 기존 카드들과 개념이 중복된다 |
| **C. 혼합** | `post` 를 만들되 카드 생성 시 `post` 도 함께 남긴다 | 피드는 단일 테이블, 콘텐츠는 기존 것 재사용 | 이중 쓰기. 정합성 관리 부담 |

판단에 필요한 질문: **사용자가 "글을 쓴다"는 새 행동을 하길 원하나, 아니면 지금 만드는 카드들이
자연스럽게 피드에 보이길 원하나?**

## 2. 가시성 모델 — 피드의 전제

[overview.md](overview.md) 에 적었듯 **지금 공개/비공개 개념이 스키마에 없다.**
피드를 만들려면 먼저 이걸 정의해야 한다.

```
공개(public)      누구나 — 피드 2번에 흐른다
팔로워(followers) 팔로우한 사람만
그룹(group)       그 그룹 멤버만 — 지금 기도카드의 실제 의도
비공개(private)   나만
```

- **기존 데이터는 전부 `group` 으로 시작한다.** 기본값이 공개면 사고다
- 작성 시 사용자가 고를 수 있어야 한다
- 이 모델대로 **RLS 를 다시 써야 한다** = security-backlog 1번

## 3. 그룹 기도카드가 피드에 섞이는 문제

목표 3번("내 그룹에서 업데이트된 기도카드")은 앞의 둘과 **성격이 다르다.**

- 팔로우 기반이 아니라 **멤버십 기반**이다
- 기도카드는 민감하다 — 피드에 섞이면 **스크롤하다 남에게 어깨너머로 보일 위험**이 커진다
- 그룹 탭에도 같은 내용이 있다. 중복 노출이 맞나?

**대안**: 피드에는 "○○ 그룹에 새 기도카드 3개" 같은 **요약 카드**만 띄우고, 본문은 그룹 탭에서 보게 한다.
민감도와 유입을 모두 챙기는 방법이다. — 결정 필요

## 4. 기술적으로 어려운 것 (착수 전 조사 필요)

| 쟁점 | 내용 |
|---|---|
| **피드 쿼리** | 여러 소스를 시간순으로 합치고 페이지네이션. `created_at` 커서 기반이 무난하지만 소스가 3개면 각각 커서가 필요하다 |
| **RLS 와 성능** | 멤버십·팔로우 조인이 RLS 서브쿼리로 들어가면 느려진다. 인덱스 설계 동반 필요 |
| **빈 피드** | 팔로잉이 0명인 신규 사용자에게 무엇을 보여주나 (추천? 공개 인기글?) |
| **정렬** | 시간순으로 시작하는 것이 정직하다. 랭킹은 나중 문제 |
| **신고·차단** | 공개 피드에는 부적절한 콘텐츠가 온다. 지금 신고는 **Discord 웹훅뿐**이다 (backlog: 신고 테이블화) |
| **어드민 조회 부담** | `apis/admin.ts` 가 클라이언트 집계라 RLS 정비 시 깨진다는 주석이 이미 있다 |

## 5. 운영·정책 (기술 밖의 문제)

공개 피드를 여는 순간 **콘텐츠 모더레이션 책임**이 생긴다.

- 부적절한 게시물 신고 → 처리 흐름 (지금은 Discord 웹훅 + 어드민 수동 삭제)
- 종교 커뮤니티 특성상 **교리 논쟁·이단 시비**가 생길 수 있다
- 미성년 사용자 보호

**기능보다 이쪽이 먼저 막힐 수 있다.** 별도 논의가 필요하다.
