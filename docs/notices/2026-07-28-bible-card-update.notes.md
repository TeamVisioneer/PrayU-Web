### GIF 만드는 법

앱의 실제 뒤집기 애니메이션을 실시간 녹화하면 프레임 간격이 들쭉날쭉하다.
대신 앱에서 **앞뒤 정지 화면 두 장**을 찍고, 합성 페이지에서 회전각을 프레임마다
직접 지정해 찍는다 — 프레임 수·간격이 정확해진다.

### 화질 — 팔레트를 아끼면 그라디언트가 깨진다

말씀카드 배경이 그라디언트라 **색을 아끼면 대각선 줄무늬(밴딩)** 가 생긴다.
원본 PNG 프레임은 매끈한데 GIF 로 만들면 줄이 보이는 식이다.

- 팔레트를 64 → 256색으로 늘려도 **디더링 없이는 줄무늬가 남는다**
- **`dither=sierra2_4a`** 를 넣으면 사라진다. 오차를 이웃 픽셀로 흩어 계단을 없애는 방식이다

인코딩은 **ffmpeg**(`palettegen=max_colors=256:stats_mode=full` + `paletteuse=dither=sierra2_4a`).
순수 JS(gifenc)로도 만들 수 있으나 디더링이 없어 이 그라디언트에서는 밴딩을 피하지 못했다.

용량을 줄인 방법:
- 녹화 컨텍스트를 **`deviceScaleFactor: 1`** 로 (레티나면 픽셀이 4배)
- 정지 구간은 같은 프레임을 여러 장 넣지 않고 **concat 의 `duration`** 으로 표현하고
  `-fps_mode passthrough` 로 GIF 의 프레임별 delay 에 그대로 싣는다
  (fps 를 고정하면 0.9초·1.6초 정지가 같은 프레임 수십 장으로 펼쳐져 오히려 커진다)

스크립트: 스크래치패드 `capture/notice-gif-ffmpeg.mjs` · 정지 이미지는 `capture/notice-shots-v2.mjs`
(로컬 시드 계정으로 촬영: `./scripts/seed-dev.sh` → `/dev/login`)
